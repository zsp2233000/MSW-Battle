# 地圖與編隊規範

`map/map01.map` 是模擬地圖與後續戰場的尺寸基準。`map/formationsim.map` 使用相同的 RectTileMap 地形與 BattleCameraAnchor 設定；新增戰場依此大小製作，保持保存編隊的座標相容。

| 項目 | 基準 |
|---|---|
| TileMapMode | 1 / RectTile，無重力 |
| 地形尺寸 | 29 × 8，共 232 個地塊 |
| 地塊索引 | X=-15..13，Y=-5..2 |
| GridSize | 1 × 1 世界單位 |
| 世界邊界 | X=[-15,14)，Y=[-5,3) |
| 座標系 | 沿用 map01 原點、地塊容器 Transform 與尺度；不可任意平移或縮放 |
| 相機 | 沿用 map01 的 BattleCameraAnchor 與固定相機腳本 |

地塊格線是地形資料，並非布陣槽位。兵種直接放在地圖上，保存 `monsterId`、`x`、`y` 的連續世界座標；不得將落點取整或吸附到固定格子。伺服器以 map01 的真實地形檢查邊界、缺失地塊及牆壁，並要求單位之間至少相距 0.3 世界單位。當前每組可放 1–6 個單位，同兵種可重複。

模擬地圖的預覽為各客戶端自己的純視覺實體，採用正式 MonsterCatalog 的待機動畫；不掛戰鬥、碰撞或 AI 元件。左鍵選取／放置／移動；右鍵移除，亦可使用工具列的移除按鈕。工具列覆蓋區域不接受地圖放置。

後續新增地圖時，透過 MapBuilder 從 map01 複製，移除不屬於新地圖的控制器，保持地形範圍、原點及 GridSize；不可連帶改動 map01。地形可以後續設計，但若更改可行走區域，必須加入該戰場的落點驗證與既有編隊修正流程，不能只因外框尺寸相同就直接套用編隊。目前模擬地圖維持與 map01 完全相同的地形。

驗證：`node --test tests/formation_contract.test.cjs` 比對模擬地圖與 map01 的地形、尺寸及相機，並檢查 UI 沒有站位格、預覽沒有戰鬥元件。Maker runtime 探針另外驗證小數座標放置、移動、移除、跨圖清理與儲存還原。
