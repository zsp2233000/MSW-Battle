# Battle POC — Milestone Roadmap

> 🔖 跨里程碑方向：先證明單局部署與自動戰鬥，再建立持久編隊與真人配對，逐步銜接國戰。
> 本文件不是 GDD；當前契約以 `BattlePOC-M1-GDD.md` 為準。
> 最後更新：2026-11-19

編隊與後續地圖共用 map01 的現行 209 地塊地形、相機及 x=0.5 水平鏡射軸；兵種直接放置於地圖的連續世界座標。詳見 [地圖與編隊規範](Map-Formation-Standard.md)。

## 願景與發布條件

- 願景：玩家事先整備不同職能的怪物編隊，配對後觀看陣型與兵種配置決定勝負；長期以多場戰果支援陣營爭奪據點。
- 發布條件：部署操作清楚、戰鬥結果可靠、完整視聽回饋可辨識，且一局可從配置無阻塞地進行至結算。

## Milestones

| M | 主題 | 狀態 |
|---|---|---|
| M1 | 單人對關卡預配置敵軍的完整 POC → `BattlePOC-M1-GDD.md` | 🔨 active (Phase 1/5 done) |
| M2 | 個人功能大廳、五組持久編隊與出戰編隊選擇，接上含等候計時及取消操作的跨 instance 真人一對一自動戰鬥（設計已確認）；配對對戰加入怪物等級（Lv1–30）與陣亡經驗（ADR 0005、[#63](https://github.com/zsp2233000/MSW-Battle/issues/63)） | planned |
| M3 | 依 POC 測試結果擴充關卡、怪物種類與既有怪物資料表 | candidate |

## Backlog（需要，但尚未排入）

- 國戰大地圖——不同 world instance 的玩家看到相同的據點歸屬。（補記：2026-11-24 已做首版，見 ADR 0015。在城鎮中查看，依高雄行政區的實際排列顯示歸屬、兵力與相鄰關係，只能查看；戰果寫入後由伺服器推送給開著地圖的玩家。發布環境多個 instance 的推送尚未驗證。）
- 國戰陣營——玩家自由選擇並持續所屬，重新登入仍保留身分；加入、轉陣營與人數平衡規則留到後續。
- 國戰配對——以雙方玩家當下所在的城鎮為準。只有雙方都在線，且分處兩座相鄰城鎮時，才可配對。
- 據點爭奪——第一版試玩時，每座城鎮的滿兵力為 100 點。每場勝利固定扣除敗方所在城鎮 20 點兵力，險勝與大勝相同。敵方對滿兵力城鎮累積 5 勝，兵力即降至 0，由勝方陣營立即取得該城。易主時該城兵力立即回滿 100 點。同時進行中的對局如何結算，仍待決定。
- 模擬地圖的 AI 試打——本次先提供布陣與儲存；試打及配對成功時中斷試打的流程留到後續。
- 歷史戰績與斷線重返原戰場——本次只顯示當局結果，結束後返回個人功能大廳；跨登入戰績與回到原對局留到後續。（補記：斷線重返已於 #109 完成，見 ADR 0014 決定四與決定五；只有一位真人的守衛戰，這位玩家真的離開後該局中止，跨登入戰績仍留到後續。）
- 行動裝置輸入與版面適配——M1 僅驗證 PC 滑鼠操作。
- 多張戰場地圖——後續依 map01 的大小製作，保持編隊座標相容；地形變更須驗證保存編隊落點。
- 局內重開／再戰流程——M1 以重新 Play 取代。
