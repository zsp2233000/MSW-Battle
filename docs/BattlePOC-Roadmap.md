# Battle POC — Milestone Roadmap

> 🔖 跨里程碑方向：先證明單局部署與自動戰鬥，再建立持久編隊與真人配對，逐步銜接國戰。
> 本文件不是 GDD；當前契約以 `BattlePOC-M1-GDD.md` 為準。
> 最後更新：2026-10-18

## 願景與發布條件

- 願景：玩家事先整備不同職能的怪物編隊，配對後觀看陣型與兵種配置決定勝負；長期以多場戰果支援陣營爭奪據點。
- 發布條件：部署操作清楚、戰鬥結果可靠、完整視聽回饋可辨識，且一局可從配置無阻塞地進行至結算。

## Milestones

| M | 主題 | 狀態 |
|---|---|---|
| M1 | 單人對關卡預配置敵軍的完整 POC → `BattlePOC-M1-GDD.md` | 🔨 active (Phase 1/5 done) |
| M2 | 個人功能大廳、五組持久編隊與出戰編隊選擇，接上含等候計時及取消操作的跨 instance 真人一對一自動戰鬥（設計已確認） | planned |
| M3 | 依 POC 測試結果擴充關卡、怪物種類與既有怪物資料表 | candidate |

## Backlog（需要，但尚未排入）

- 國戰大地圖——不同 world instance 的玩家看到相同的據點歸屬；使用者明確排除於本次範圍，呈現與操作形式待後續決定。
- 國戰陣營——玩家自由選擇並持續所屬，重新登入仍保留身分；加入、轉陣營與人數平衡規則留到後續。
- 據點爭奪——已確認累積多場戰果，達門檻便立即換主；分數算法、換主後仍在進行的對局與競爭結算規則留到後續。
- 模擬地圖的 AI 試打——本次先提供布陣與儲存；試打及配對成功時中斷試打的流程留到後續。
- 歷史戰績與斷線重返原戰場——本次只顯示當局結果，結束後返回個人功能大廳；跨登入戰績與回到原對局留到後續。
- 行動裝置輸入與版面適配——M1 僅驗證 PC 滑鼠操作。
- 多張戰場地圖——先確認單張 `map01` 的戰鬥節奏與空間尺度。
- 局內重開／再戰流程——M1 以重新 Play 取代。
