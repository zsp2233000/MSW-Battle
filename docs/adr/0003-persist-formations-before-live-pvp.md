# 以持久編隊銜接真人對戰與後續國戰

玩家先在世界內的整備區保存預存編隊，持久保存兵種、數量與相對站位，重新登入後仍可使用。對戰採兩名在線玩家各帶一支預存編隊，進入同一戰場觀看自動戰鬥；每次進戰場重新配兵的流程改由戰前整備承擔。預存編隊與 ADR 0002 的關卡預配置單位是不同概念。

本次範圍先完成遊戲大廳、玩家資料與編隊持久化，以及跨 world instance 的真人一對一配對對戰。大地圖、陣營加入與據點結算留到後續，以先驗證完整對戰流程、再接上國戰；里程碑安排以 [Roadmap](../BattlePOC-Roadmap.md) 為準。

每名玩家可保存五組預存編隊，每隊一至六個單位、兵種可重複，所有玩家使用相同可選兵種池。五組之中選定一組出戰編隊；玩家可編輯其他組配置並先保存，進入戰場時使用啟用的出戰編隊。儲存與切換出戰組是分開的操作，只有「設為出戰編隊」才更換啟用組；例如第一組出戰、編輯第二組時，儲存只更新第二組，不會將第二組自動設為出戰。編隊配置仍是單一功能，玩家在模擬地圖編輯，未儲存變更只留在該玩家的 client（2026-10-31 修訂，取代「排隊期間也可以繼續調整」；等待配對時的編輯鎖定由 #52 整合）。雙方入場流程完成後直接戰鬥，沒有第二次準備確認。

按下配對時，固定當下已保存且有效的出戰編隊內容，作為本局編隊。後續編輯、保存或切換出戰組不改變本局編隊；要更換本局使用的內容，須先取消再配對。即使正在編輯的就是啟用出戰組，其後續保存的新內容也只供之後的對局使用。

配對成功後直接使用本局編隊進場，不保存任何編輯內容（2026-10-31 修訂，取代原「自動儲存目前編輯組」與「草稿跨入戰場及返回須攜帶」）。交接資料只含已保存編隊、出戰選擇、本局編隊及必要的配對狀態與版本保護；舊版仍在途的交接紀錄若帶有未保存內容，讀取時忽略，不還原。

2026-10-18 需求修訂：由一組擴為五組，保存與出戰選擇分離；原先配對成功後的保存／捨棄提示與三十秒倒數，改為自動保存目前編輯組後直接進場。保存失敗仍繼續使用本局編隊，避免編輯中的配置阻塞已成立的對戰。

2026-10-31 需求修訂（[#50](https://github.com/zsp2233000/MSW-Battle/issues/50)）：未儲存變更改為只存在 client，儲存只更新當組，切組或離開時由玩家選擇儲存、捨棄或繼續編輯。理由：伺服器 session 保留可恢復草稿會讓「已儲存」與「正在改」兩種權威並存，並迫使配對成功時替玩家代選儲存、交接資料攜帶未確認內容；改由玩家明確決定後，儲存成功才是唯一的權威變更點，交接與配對也不再受編輯內容牽動。因此以下舊規則廢止：排隊期間可編輯、同次登入跨地圖保留草稿、配對成功自動儲存、交接攜帶草稿。預存編隊、出戰編隊與本局編隊的區分，以及「儲存與設為出戰分離」不變。

第一版採個人功能大廳，提供整備、設定及配對入口；模擬地圖先提供布陣與儲存，不包含對 AI 試打。其他編隊欄位可留空，只要有一組已保存、有效且啟用的出戰編隊，就能加入配對池。

配對持續到成功或玩家主動取消，不以等候六十秒為由結束。大廳及模擬地圖須提示配對狀態、顯示已等候時間並提供取消操作；計時器顯示已等待時間，不是結束配對的倒數。

未儲存變更不跨地圖保留（2026-10-31 修訂，取代原「草稿在大廳與模擬地圖之間切換時保留」）：離開編輯或切換組別時由玩家選擇儲存、捨棄或繼續編輯，重新進入只載入已保存版本。唯一的保存時點是玩家明確按下儲存，包含確認視窗中的「儲存並切換／返回」；編輯不會自動覆蓋預存編隊。

已開始的自動戰鬥不因玩家斷線直接判負，仍繼續完成；若雙方都離開且戰場被回收，該局視為中止，預存編隊保留。本次只顯示當局戰鬥結果，結束後返回個人功能大廳；歷史戰績與斷線重返原戰場留到後續，安排以 Roadmap 為準。
