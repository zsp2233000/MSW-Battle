# 奪城者返回出發城，不進入剛奪下的城鎮

2026-11-24 使用者決定：奪城只改變城鎮歸屬，不帶人移動。打完一場的每個人返回時都回出發城；出發城在結算後已不屬己方，就回己方主城。想進入新奪下的城鎮，玩家自己走傳送門。詞彙依 CONTEXT.md（奪城、落點、主城、過期戰果）。

這取代了下列 ADR 的落點規則：ADR 0010 的補記「奪城者進新城」、ADR 0012 的落點段落、ADR 0013 中「奪城者也能帶著完成的結果落點」的理由，以及 ADR 0014 中「奪城者的偏好城是被奪下的城」一句。這些 ADR 的其他決定不變，包括「先套用戰果、再看歸屬」的次序、用已存的戰果紀錄判斷落點，以及登入時只判斷一次。

為什麼：落點只剩一條規則（出發城仍屬己方就留下，否則回主城），結果頁的返回按鈕因此能直接寫出目的地，也只會因為出發城失守而改變。原本只有奪城者會移動，同一場的隊友留在原地，玩家不容易理解。

## 後果

- 返回前仍要等結算寫完（`LandingWaitSeconds`）。原因有兩個：真人戰落敗時，本場就可能讓出發城失守，落點要等結果確定；而且還在重試的結算會隨房間關閉一起中止，要靠返回的玩家把房間留到寫入完成。
- 城鎮提示「上一場戰果：奪下 X」照樣保留，只是告知發生了什麼，不再代表玩家人在 X。
- 斷言「奪城者進新城」的測試與探針要改成「回出發城」。
