# 怪物等級由「玩家 × 怪物」持有，怪物經驗值由陣亡取得

每名玩家對每個怪物持有一個怪物等級（上限 30）與怪物經驗值；同一編隊中重複放置的同一怪物共用該等級，不引入「玩家持有的個體」。預存編隊只記錄兵種、數量與相對站位（ADR 0003），若以個體為單位，編隊、存檔與配對交接都須改寫，並衍生個體刪除、跨編隊共用等新問題；所有玩家仍使用相同可選兵種池，只是等級各自不同。

怪物經驗值只在配對對戰中、由玩家自己陣亡的戰鬥單位取得，存活與擊殺都不取得。這是刻意反過來的設計：擊殺得經驗會讓強者越打越強、弱者永遠追不上；陣亡得經驗讓輸方成長較快，拉近差距。不要把它「修正」成擊殺得經驗。

怪物經驗值在戰鬥結果產生時結算，中途離開戰場的玩家也照樣結算，由伺服器依該玩家識別寫入其存檔；中途放棄的多半是輸方，而輸方正是這套追趕設計要照顧的對象。

配對對戰直接使用雙方真實等級，配對不考慮等級差，追趕交給陣亡經驗承擔。不屬於任何玩家的戰鬥單位（Legacy 關卡流程、Maker 測試編隊、固定敵軍）一律以 Lv1 作戰，也不取得經驗。
