# UI 重設設計筆記

狀態：2026-10-28 使用者選擇 B「戰術沙盤」方向與棕色半透明層次，並明確指定繼續使用正式遊戲目前的 Cardgame 素材；B 原型已完成素材統一。

正式需求與驗收條件以 [規格 #44：以 Cardgame 素材重設 B「戰術沙盤」全流程 UI](https://github.com/zsp2233000/MSW-Battle/issues/44) 為準。本文件保留設計選擇、原型索引與既有驗證紀錄，不作為另一份獨立規格維護。

- 規格已發布並標記 `ready-for-agent`，完整玩家流程的驗收切入點已獲使用者確認。
- 拆票草案為大廳、布陣與情報、保存與返回、戰鬥 HUD 與結果、配對與完整往返五票；粒度與依賴尚待使用者確認，子議題尚未發布。
- 正式 UI 與遊戲腳本尚未套用改版。以下原型檢查不代表正式五個畫面已通過驗收。

## 已確認方向

2026-10-28，使用者確認：

- 範圍涵蓋遊戲大廳、編隊整備、配對、戰鬥 HUD 與戰鬥結果；先以大廳與編隊整備製作原型，確認後延伸至其他畫面。
- PC 優先，以滑鼠操作為主要設計與驗收目標。
- 外觀採嚴肅軍事風格，以棕色為主色，沿用 Cardgame 既有木紋。軍事年代及額外皮革、金屬等材質尚未指定，不視為已確認需求。
- 體驗優先協助新玩家理解選怪布陣、保存、設為出戰與配對；下一步、目前出戰編隊與未保存狀態須清楚，詳細資訊於選取或展開後查看。
- 編隊整備以戰場為畫面主體，怪物列表與操作面板圍繞戰場安排；常用操作固定可見，避免遮擋放置、選取與移動單位。
- 遊戲大廳以目前出戰編隊與開始配對為主要內容，提供五組編隊切換與整備入口；沒有有效出戰編隊時，主要按鈕引導前往整備。
- 怪物列表保持精簡；選取後顯示種類、生命值、傷害、攻擊間隔與攻擊距離，座標等技術資訊收進詳細資訊。
- 以 B「戰術沙盤」作為後續設計基礎，增加部分邊框與半透明面板的質感。
- 使用者明確選擇 Cardgame（Maple Duel，正式遊戲目前使用）套件。原型與後續實作須以它的現成素材為基礎，棕色與半透明調整應保留其可辨識的美術風格。

## 既有遊戲規則

依 [CONTEXT.md](../CONTEXT.md) 與 [ADR 0003](adr/0003-persist-formations-before-live-pvp.md)：

- 玩家有五組預存編隊，每組一至六個單位。
- 保存編隊與設為出戰是分開的操作。
- 配對開始時固定本局編隊；後續保存與切換出戰組僅影響之後的配對。
- 編隊草稿、預存編隊與本局編隊須在介面中保持可辨識。
- 等候時間是已等待時間；配對持續至成功或玩家取消。

## 原型比較範圍

- 先比較三種版面結構不同的大廳與編隊整備方案，皆遵循棕色、嚴肅軍事與 PC 優先的方向。
- 比較資訊層級、操作區配置、戰場可見範圍，以及能搭配現有怪物形象的材質與裝飾。
- 原型須呈現目前編輯組、未保存狀態與目前出戰組的差異；排隊時須能辨識本局編隊已固定。
- 版面選定後，將相同視覺語言延伸到配對、戰鬥 HUD 與戰鬥結果。

## B 方案質感細化

- 主要戰場、情報與操作區改用 Cardgame 原始面板框；此前以純色細線組裝的護角已移除，避免取代套件的美術風格。
- 面板底色使用 63%～92% 不透明度，搭配低對比棕色底紋；情報與操作區較深，戰術桌較通透。
- 透明度僅施加在背景 Sprite，文字與根 Canvas 保持 100% 不透明度。
- 七個 Cardgame 面板框只渲染邊框（`FillCenter=false`），讓半透明底色仍可透出；邊框與木紋不接收點擊。既有控制項 UUID 保留。
- B 的 19 個按鈕改用 Cardgame 原始底圖與 SpriteSwap 互動圖片；保留套件原色與白字黑色描邊。Casual Survival 主按鈕已從 B 移除。
- 比較頁現在預設開啟 B；A、C 保留供參考。瀏覽器材質仍為近似預覽。

## 驗收重點

- 新玩家能辨識下一步，依序完成布陣、保存、設為出戰與開始配對。
- 保存某組編隊不會被誤解成已切換出戰編隊。
- 配對期間的編輯與保存不會讓玩家誤以為本局編隊已更新。
- 選取怪物後能查看戰術資料，同時保持戰場與常用布陣操作清楚可見。

- 可互動比較頁由原生版面資料產生，位於本機暫存輸出 `C:/Users/zsp22/AppData/Local/Temp/msw-ui-redesign/index.html`；以瀏覽器開啟即可，無須啟動伺服器或安裝套件。此路徑屬本機暫存，其他電腦與清除暫存後不適用。
- 以 `?variant=A|B|C&screen=Lobby|Editor` 選擇畫面；底部按鈕或左右方向鍵切換方案。可試用選怪、布陣、保存、設為出戰、開始與取消配對，資料僅存在頁面記憶體。
- 怪物名稱與五項情報（種類、生命值、傷害、攻擊間隔、攻擊距離）取自現有 `MonsterData.csv` 的三隻怪物；圖像取自其待機動畫的靜態影格。瀏覽器的按鈕材質與字體為近似預覽，實際 MSW 9-slice 與字體須由 Maker 確認。
- B 的瀏覽器預覽已嵌入 Cardgame 原始美術縮圖，並呈現一般、移入、按下與停用圖片；縮圖的解析度有限，仍以 Maker 的原始 RUID 渲染為準。
- 戰場為連續站位的示意圖；原型操作未實作正式地形與部署間距驗證，不代表已改動遊戲站位規則。
